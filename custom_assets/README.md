# Original design assets

This folder keeps the supplied files under their original names:

- `website cover.svg` and `website cover.jpg`: background design.
- `written name.svg` and `written name.jpg`: handwritten name design.
- `apple pencil sketch favicon.svg`: original apple drawing. The footer uses a display copy at `assets/images/branding/apple-sketch.svg`.

The site uses a display copy of the SVG cover at `assets/images/backgrounds/website-cover.svg`. It uses the existing header logo at `assets/images/branding/jacy_logo.svg`.

When a design changes, update its display copy too. The files here are source references; pages should link to display assets in `assets/`.
